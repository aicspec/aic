# Handing a contract to the user for review

A contract you wrote is a proposal until the user accepts it.

1. Summarise it in a few lines: the Modules and Boundaries, every open Decision, since those are theirs to settle, and what is still Draft.
2. Ask them to open the file at https://aicspec.dev/editor/ with File > Open YAML. The editor draws it, checks it and lists what is open. It runs in the browser and uploads nothing.
3. In Chrome and Edge, Save writes their changes back to the same file. Elsewhere they can paste the YAML with File > Paste YAML and download the result.
4. When they are done, read the file again before you go on, because they may have changed it. Comments in the YAML are lost if it is saved from the editor, so keep rationale in Decisions.
